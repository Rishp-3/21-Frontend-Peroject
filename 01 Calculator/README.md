# 🧮 Calculator

A simple and responsive **Calculator Web Application** built using **HTML, CSS, and JavaScript**.

This project provides basic arithmetic operations with a clean and simple calculator interface.

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* `%` Percentage calculation
* `AC` — Clear all values
* `⌫` — Backspace
* `.` — Decimal number support
* `=` — Calculate result
* Division-by-zero error handling
* Simple and clean UI

## 🛠️ Technologies Used

* **HTML5** — Calculator structure and buttons
* **CSS3** — Layout and styling
* **JavaScript** — Calculator logic and operations

## ⚙️ How It Works

The calculator interface is created using HTML buttons for numbers and operations.

JavaScript handles:

* User button clicks
* Number input
* Decimal input
* Arithmetic operations
* Percentage calculation
* Backspace
* Clearing the calculator
* Displaying the result
* Division-by-zero error handling

The calculator stores the first number, second number, and selected operation separately before calculating the final result.
