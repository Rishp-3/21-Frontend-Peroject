# 💬 Random Quote Generator

A simple and interactive **Random Quote Generator** built using **HTML, CSS, and JavaScript**.

The application displays a random quote along with its author. Click the **Generate Quote** button to get a new quote.

---

## 🚀 Features

- 🎯 Generate random quotes
- ✍️ Display quote author
- 🔄 Generate a new quote with one click
- ⚡ Fast and lightweight
- 🎨 Clean and simple UI
- 📱 Responsive design
- 🧩 Uses JavaScript DOM manipulation

---

## 🛠️ Technologies Used

- **HTML5** — Structure
- **CSS3** — Styling and layout
- **JavaScript** — Logic and dynamic content
